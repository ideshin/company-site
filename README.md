# スカイラインテクノロジー 企業サイト

架空の企業「スカイラインテクノロジー株式会社」のトップページです。HTML / CSS / JavaScript を `index.html` 1 ファイルにまとめているため、ビルドやインストールをしなくてもブラウザで開くだけで表示できます。

> ※ このサイトは架空の企業のサンプルです。社名・人物・事例はすべて創作です。

## サイトの概要

スカイラインテクノロジーは、建築と都市開発のためのソフトウェアをつくる会社という設定です。トップページには次のセクションがあります。

| セクション | 内容 |
| --- | --- |
| お知らせ | 製品リリース、展示会出展、拠点開設などの新着情報 |
| ヒーロー | キャッチコピー「都市の高さを、データで設計する。」と、Canvas で描画するスカイライン（街並みの断面図） |
| 製品 | SKYLINE Massing（ボリューム検討）、SKYLINE Shadow（日影・眺望解析）、SKYLINE Ops（竣工後の設備運用）の 3 製品と、対応ファイル形式 |
| 導入事例 | 設計事務所・デベロッパー・ビル管理会社での導入効果 |
| 会社概要 | 企業理念と、商号・設立・資本金・所在地などの会社情報 |
| お問い合わせ | 電話・メールの連絡先と問い合わせフォーム |

### 主な特徴

- ライト / ダークモードに対応しています（OS の設定に追従）
- スマートフォンなどの狭い画面幅でも崩れないレスポンシブレイアウトです
- フォントは Google Fonts から読み込みます（オフラインでは代替フォントで表示されます）

## ブラウザで index.html を開く手順

### 方法 1: ファイルを直接開く

1. Finder（Windows の場合はエクスプローラー）でこのフォルダを開きます。
2. `index.html` をダブルクリックします。
3. 既定のブラウザでページが表示されます。

別のブラウザで開きたい場合は、`index.html` を右クリックして「このアプリケーションで開く」（Windows では「プログラムから開く」）からブラウザを選ぶか、ブラウザのウィンドウに `index.html` をドラッグ＆ドロップします。

### 方法 2: ターミナルから開く

プロジェクトのフォルダで次のコマンドを実行します。

```bash
# macOS
open index.html

# Windows（PowerShell / コマンドプロンプト）
start index.html

# Linux
xdg-open index.html
```

### 方法 3: ローカルサーバーで開く（任意）

`http://` の URL で確認したい場合は、簡易サーバーを起動します（Python 3 が必要です）。

```bash
python3 -m http.server 8000
```

起動したら、ブラウザで <http://localhost:8000/> を開きます。終了するときはターミナルで `Ctrl + C` を押します。
